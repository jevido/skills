# Dutch for the main documentation

Use together with `../allunited-docs-sports/NL-GUIDE.md` (voice, links, front
matter, general glossary, done checklist). This file adds the menu titles and
platform terms for the main documentation.

The English pages carry no Dutch glosses, so you choose the Dutch word a
Dutch club volunteer or AllUnited colleague uses. Use the same word every
time; add new decisions to the list at the bottom.

## Status words

Live → Live · Pilot → Pilot · Built → Gebouwd · Idea → Idee. Callout title:
"Status: Pilot", without a date. "On the roadmap" → "staat op de roadmap".
